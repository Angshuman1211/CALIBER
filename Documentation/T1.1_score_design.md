# T1.1 — Operator-Aware Score Design

**Task:** T1.1 — Operator-aware score design
**Track:** 1 — Methodology, Calibration and Theoretical Guarantees
**Deliverable (blueprint §15):** Definition and reference implementation of the hallucination score from the null-space / range decomposition
**Status:** In progress
**Branch:** `T1.1`

---

## Objective

Define **what the hallucination score is** and implement it as a reference. This task ends with a scalar score per region, computed from a set of solver draws and a known forward operator — and nothing more. No threshold, no flag, no coverage number; those are T1.2.

**Why the score comes first:** conformal calibration is score-agnostic. It will happily produce a *valid* flag from a useless score, and the result is a technically correct paper with no detection power. Validity comes from T1.2 regardless of what happens here; **all** of the detection power comes from this task. The score is also the only part of the pipeline specific to this problem — everything downstream is adapted from the conformal literature.

---

## Design principle — the score lives in the null space (D2)

Because A is known, every reconstruction splits into a range component (pinned by the data) and a null-space component (invisible to the operator). Hallucination can *only* live in the latter. The score therefore emphasises structure in the free component that **also disagrees across independent solver draws**, combined with evidence from the measurement residual:

- **null-space energy** — is there structure here the data never constrained?
- **cross-sample disagreement** — do independent draws from the prior disagree about it? (Structure stable across draws is prior-consistent; structure that flips between draws is invented.)
- **measurement residual** — does the reconstruction actually explain the data it was given?

The three are combined into one scalar per region. Each must be computable **without ground truth** — the entire point is warning a user at deployment, where the true image does not exist. Any component that sneaks in a reference image is disqualified no matter how well it scores.

## Design principle — no calibration in this task

The temptation is to wire up split conformal early because it is easy and produces a satisfying coverage number. The risk is that the number is computed under a *fixed* operator, looks fine, and quietly establishes the wrong baseline in everyone's head — the project's whole claim is that exactly this number is misleading. Score ranking is the only thing measured here; the naive-conformal baseline exists to be shown failing (T1.2), not to reassure.

---

## Design principle — the decomposition is on trial, not assumed

The ablation matrix (T1.4) will isolate each component, because a reviewer will ask which one is doing the work. It is entirely possible that **cross-sample disagreement alone is competitive**, which would be an honest and publishable negative finding about the operator decomposition — and it is better to discover that here, at reference-implementation scale, than in Phase 3. Build the components as separable from the start so the ablation is a config change.

---

## Metrics

No coverage numbers in this task. What it must produce instead:

- **Score sanity:** does the score rank known-hallucinated regions above clean ones on a small hand-checked set? A score that fails this cannot be rescued by calibration.
- **Component separation:** null-space energy, cross-sample disagreement, and residual should not be measuring the same thing — show their correlation is low enough to justify combining them.
- **Cost:** measured seconds per solver draw and per score evaluation → feeds the T1.4 experiment budget.
