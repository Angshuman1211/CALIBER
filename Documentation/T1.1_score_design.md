# T1.1 — Operator-Aware Score Design

**Task:** T1.1 — Operator-aware score design
**Track:** 1 — Methodology, Calibration and Scientific Direction
**Deliverable (blueprint v3.0 §18):** Definition and reference implementation of the hallucination score from the null-space / range decomposition
**Status:** In progress
**Branch:** `T1.1`

---

## Objective

Define **what the hallucination score is** and implement it as a reference. This task ends with a scalar score per region, computed from a set of solver draws and a known forward operator — and nothing more. No threshold, no flag, no coverage number; those are T1.2.

**Why the score comes first:** conformal calibration is score-agnostic. It will happily produce a *valid* flag from a useless score, and the result is a technically correct paper with no detection power. Validity comes from T1.2 regardless of what happens here; **all** of the detection power comes from this task. The score is also the only part of the pipeline specific to this problem — everything downstream is adapted from the conformal literature.

---

## Design principle — the score lives in the null space (D2)

Because A is known, every reconstruction splits into a range component (pinned by the data) and a null-space component (invisible to the operator). Hallucination can *only* live in the latter. The score therefore emphasises structure in the free component that **also disagrees across independent solver draws**, combined with evidence from the measurement residual:

- **null-space energy** — is there structure here the data never constrained?
- **cross-sample disagreement** — do independent draws from the prior disagree about it? (Structure stable across draws is prior-consistent; structure that flips between draws is invented.)
- **measurement residual** — does the reconstruction actually explain the data it was given?

The three are combined into one scalar per region. Each must be computable **without ground truth** — the entire point is warning a user at deployment, where the true image does not exist. Any component that sneaks in a reference image is disqualified no matter how well it scores.

### WI-2 is not blocked on Track 2 (corrected 2026-08-21)

This was previously recorded as blocked on the Track 2 operator pipeline. It is not. For Cartesian MRI undersampling the forward operator is `A = M·F` with `M` a diagonal binary mask in k-space and `F` the Fourier transform, so the projectors are

```
P_range = F* M F        P_null = I − F* M F
```

Both are computable **from the mask alone**, with two FFTs and an elementwise multiply. No data, no credentials, no solver, no partner deliverable. Track 2's T2.1 supplies masks *at scale and with regime labels attached*; it does not supply the mathematics. Build the projectors now against masks generated locally, and swap in T2.1's registry when it lands — the interface is a boolean array of k-space shape.

This also unblocks the substrate Q1 depends on (§ Open Questions in `problems_and_decisions.md`): the subspace-distance candidates for operator distance are functions of `P_null` for two operators, so the distance measures become testable as soon as the projectors exist.

### WI-4 and WI-5 are partially unblocked

Only the parts needing *real solver draws on real volumes* are blocked, and that is narrower than it looks.

- **Code path.** Build the score against a mock sampler satisfying the C2 interface contract (given measurements and an operator, return N draws). Mock draws with controllable dispersion exercise every branch and let the combination rule be tested before T2.2 exists. This mirrors the approach used in Obscuron: freeze the interface, build against a schema-correct stand-in, swap in the real producer later.
- **Score sanity without any solver.** For a linear A, a controlled hallucination can be *constructed*: take a clean image `x`, add `P_null·δ` for some structure `δ`. The result is exactly data-consistent (measurements are unchanged, by construction) yet contains invented structure — which is this project's definition of hallucination, made synthetically and exactly. A score that cannot rank `P_null·δ` regions above clean ones on this test is broken, and that verdict is available today. Note what this test does and does not cover: it validates the null-space-energy term and the region machinery, it says nothing about whether real solver hallucinations look like `P_null·δ`, and the cross-sample-disagreement term cannot be tested this way at all.
- **Draw budget (Q3).** The statistical half — how many draws the disagreement term needs before it stabilises — is measurable on a mock sampler with known draw variance, producing a design curve. The cost half, seconds per draw, comes from T2.2 and stays blocked. Multiply the two at integration.

**Cross-track dependencies (v3.0 numbering, partner-owned):** T2.1 supplies the operator pipeline, the masks, and the regime labels; T2.2 supplies the pretrained solver back-end that produces the draws. The v2 numbering used in earlier commits (T2.2 pipeline, T2.3 solver) is superseded — see D14.

## Design principle — no calibration in this task

The temptation is to wire up split conformal early because it is easy and produces a satisfying coverage number. The risk is that the number is computed under a *fixed* operator, looks fine, and quietly establishes the wrong baseline in everyone's head — the project's whole claim is that exactly this number is misleading. Score ranking is the only thing measured here; the naive-conformal baseline exists to be shown failing (T1.2), not to reassure.

---

## Design principle — the decomposition is on trial, not assumed

The ablation matrix (T1.4) will isolate each component, because a reviewer will ask which one is doing the work. It is entirely possible that **cross-sample disagreement alone is competitive**, which would be an honest and publishable negative finding about the operator decomposition — and it is better to discover that here, at reference-implementation scale, than in Phase 3. Build the components as separable from the start so the ablation is a config change.

---

## Metrics

No coverage numbers in this task. What it must produce instead:

- **Score sanity:** does the score rank known-hallucinated regions above clean ones? Staged — synthetic `P_null·δ` injections first (no solver needed), then a small hand-checked set of real solver draws once T2.2 lands. A score that fails the synthetic stage cannot be rescued by calibration and should not wait for real draws to be diagnosed.
- **Component separation:** null-space energy, cross-sample disagreement, and residual should not be measuring the same thing — show their correlation is low enough to justify combining them.
- **Cost:** measured seconds per solver draw and per score evaluation → feeds the T1.4 experiment budget. Score-evaluation cost is measurable now; per-draw cost arrives with T2.2.
