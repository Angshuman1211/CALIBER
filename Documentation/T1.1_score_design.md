## Objective

Define **what the hallucination score is** and implement it as a reference. This task ends with a scalar score per region, computed from a set of solver draws and a known forward operator — and nothing more. No threshold, no flag, no coverage number; those are T1.2.

**Why the score comes first:** conformal calibration is score-agnostic. It will happily produce a *valid* flag from a useless score, and the result is a technically correct paper with no detection power. Validity comes from T1.2 regardless of what happens here; **all** of the detection power comes from this task. The score is also the only part of the pipeline specific to this problem — everything downstream is adapted from the conformal literature.

---

## Design principle — the score lives in the null space (D2)

Because A is known, every reconstruction splits into a range component (pinned by the data) and a null-space component (invisible to the operator). Hallucination can *only* live in the latter. The score therefore emphasises structure in the free component that **also disagrees across independent solver draws**, combined with evidence from the measurement residual:

- **null-space energy** — is there structure here the data never constrained?
- **cross-sample disagreement** — do independent draws from the prior disagree about it? (Structure stable across draws is prior-consistent; structure that flips between draws is invented.)
- **measurement residual** — does the reconstruction actually explain the data it was given?

The three are combined into one scalar per region. Each must be computable **without ground truth** — the entire point is warning a user at deployment, where the true image does not exist. Any component that sneaks in a reference image is disqualified no matter how well it scores.

## The combination rule

```
score(r) = Σᵢ wᵢ · sᵢ(r) / scaleᵢ        wᵢ ≥ 0,  Σwᵢ = 1
```

Four decisions, each with a reason that is not aesthetic:

**Affine, not a ratio (D25).** T3.3 §3's assumption (ii) needs the score Lipschitz in the D19 operator distance. A non-negative weighted sum of Lipschitz components is Lipschitz with `L = Σ wᵢLᵢ`, immediately. The attractive alternative — `s_disagree / s_free`, "what fraction of the hidden content is unstable" — is not Lipschitz, because it diverges as the denominator vanishes in background regions. **The theory track constrained the form of the score, which is T3.3 §5's request acted on rather than deferred.**

**Standardise first (D26).** The components differ by an order of magnitude, so the v0 default of `1,1,1` was in practice `score = s_free`. Standardising is what makes the weights mean what they say and the T1.4 ablation interpretable.

**Scales frozen from the calibration operator (D27).** Re-estimating per deployment operator would pull each operator's score distribution onto a common spread — shrinking exactly the gap the project measures. Pinned by a regression test.

**Weights chosen on a design split (D28).** Conformal calibration picks a threshold, not the weights; fitting them on calibration data would leak. Default meanwhile: `1/3` each on standardised components.

### What is handed back to T3.3

Each component is Lipschitz in `d_op` **with the reconstruction held fixed** — e.g. `‖P_N^A x̂ − P_N^B x̂‖ ≤ d_op·‖x̂‖`. But `x̂` depends on the operator through the solver, which is a black box (D1). So the statement available to L1 is *Lipschitz conditional on the reconstruction*; the residual dependence flows through solver stability and is not analytically bounded here. Assumption (ii) should be split along that seam rather than assumed whole.

## The injection test — why T1.1 could be validated without a solver

For a linear operator a hallucination can be **constructed**: take clean `x`, add `P_N·δ`. Measurements are unchanged by construction, yet the image contains structure the data does not support — this project's definition of hallucination, made exactly. No solver, no dataset, no ground-truth ambiguity.

Building it surfaced **D29**. The first version failed its own data-consistency precondition, because it cast the projection with `.real`. A random 1-D mask is not conjugate-symmetric, so `P_N` of a real image has a genuine imaginary part — 33% of its norm — and discarding it puts **4.1%** of the injection back into the measured component. The full complex injection is consistent to 9.6e-8. The same pattern in `solvers/reference.py` is referred to Track 2 as D-024.

That failure was the test working. A weaker test would have passed and certified a broken construction.

---

## Design principle — no calibration in this task

The temptation is to wire up split conformal early because it is easy and produces a satisfying coverage number. The risk is that the number is computed under a *fixed* operator, looks fine, and quietly establishes the wrong baseline in everyone's head — the project's whole claim is that exactly this number is misleading. Score ranking is the only thing measured here; the naive-conformal baseline exists to be shown failing (T1.2), not to reassure.

---

## Design principle — the decomposition is on trial, not assumed

The ablation matrix (T1.4) will isolate each component, because a reviewer will ask which one is doing the work. It is entirely possible that **cross-sample disagreement alone is competitive**, which would be an honest and publishable negative finding about the operator decomposition — and it is better to discover that here, at reference-implementation scale, than in Phase 3. Build the components as separable from the start so the ablation is a config change.

## Q6 — putting `s_free` on trial (D38, D39, D40)

Q6 asks whether `s_free` fires on anatomy rather than on invention. D35 made it the question the contribution rests on: with `s_residual` structurally dead for data-consistent solvers, the score is `s_free` + `s_disagree`, and an `s_free` that tracks anatomy would leave a posterior-spread detector — a known baseline.

**Half of it is settled by algebra.** The bank's three free-component columns share one `ref_intensity` and are reductions of the same two fields, so

```
err_free² = s_free² + free_content² − 2 · s_free · free_content · cos θ
```

holds exactly (**verified at 0.00e+00 residual over 4,608 bank regions**). Under the relative criterion the label is then monotone in `u = s_free / free_content`, so the statistic matched to the label is the *ratio*, not `s_free` — and the ratio's denominator needs ground truth. `s_free` alone is mismatched to its own label by however much anatomical content varies between regions. That is Q6's mechanism, derived rather than suspected, and it points at the fix: divide by a denominator that exists at deployment, `s_range = ‖P_R x̂‖` (ask A2b). On the local phantom bank the oracle ratio flags **0.717 of the area against `s_free`'s 0.843 at identical coverage**.

**The other half needs the real-prior bank** and is one command once A2a lands. The instrument is `caliber/scoring/attribution.py` + `scripts/q6_attribution.py`, with its verdict thresholds pre-registered before the bank was available.

**What the instrument had to learn.** The obvious test — hold anatomical content fixed by stratifying on `free_content`, and see whether separation survives — is not sufficient on its own. Stratifying a *continuous* confound only attenuates it: a component built to be an exact multiple of `free_content`, with no invention signal at all, still scores 0.87 detail-matched over four bins. The fix is a paired reference: score `free_content` itself through the identical path and report the **difference**. Both are attenuated equally, so the difference survives. Against the pure anatomy meter it is exactly zero.

**And it corrects a reading elsewhere.** `err_free/free_content > 1` in every region of the M4Raw bank was taken as evidence of a mismatched prior (D-034, D37). It is not: the identity forces it whenever `cos θ < u/2`, which any prior with invention uncorrelated to the truth satisfies. The reference sampler — not a prior at all — does the same. D40 restates the check on `cos θ` directly and gives τ a physical reading: **τ = 1.75 means the prior put 1.44× as much energy into the null space as the truth had there.**

## Metrics

No coverage numbers in this task. What it must produce instead:

- **Score sanity:** **passing** on synthetic `P_null·δ` injections, for the full combination and for `s_free` alone. The real-solver stage waits on T2.2.
- **Component separation:** null-space energy, cross-sample disagreement, and residual should not be measuring the same thing — show their correlation is low enough to justify combining them.
- **Cost:** measured seconds per solver draw and per score evaluation → feeds the T1.4 experiment budget. Score-evaluation cost is measurable now; per-draw cost arrives with T2.2.
