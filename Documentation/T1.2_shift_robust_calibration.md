# T1.2 — Shift-Robust Calibration

**Task:** T1.2 — Shift-robust calibration
**Track:** 1 — Methodology, Calibration and Scientific Direction
**Deliverable (blueprint v3.0 §18):** Group-conditional and operator-distance weighted calibration converting scores into per-region flags
**Status:** Implemented and verified on synthetic score banks. Awaiting real banks (C2) for the reported result.
**Branch:** `T1.1`

---

## Objective

Turn T1.1's per-region score into a per-region **flag** with a controlled error
rate, and keep that rate honest when the acquisition operator changes between
calibration and deployment.

Everything here runs on cached score-bank values with **no GPU** (§17), which is
why T1.2 could be built while T1.1 and every solver back-end remain blocked on
T2.2. That decoupling is the score bank earning its keep.

---

## What is controlled, precisely

The **region-level miss rate**: among genuinely hallucinated regions, the
fraction the flag fails to raise. Risk control (D9), not marginal coverage of an
interval.

A region is flagged when `score >= tau`. So a *miss* is a hallucinated region
with `score < tau`, and calibration picks the largest `tau` whose miss rate is
provably at most `alpha`.

**The direction is the thing to get right.** The flag must be conservative
*downward*: when in doubt `tau` drops, more regions are flagged, and efficiency
suffers rather than validity. Every fallback path in the implementation returns
`-inf` — flag everything — which has zero misses by construction and is visibly
useless, rather than returning a plausible number that quietly under-covers.

## The three tools

| | What it does | Guarantee |
|---|---|---|
| **Tool 0** — split conformal | One threshold, calibrated at one operator, applied everywhere | The **baseline that fails**. Not a remedy |
| **Tool 1** — Mondrian | One threshold per acquisition regime | **Exact** within-group, no assumption about the shift (D3) |
| **Tool 2** — distance-weighted | Reweights every calibration region by operator distance | **Approximate** — the primary contribution (D4) |

### Tool 0 must name its calibration operator (D34)

§16's first bullet is *calibrate at one acquisition setting and apply at
others*. An early version of the API calibrated on whatever rows it was handed,
and a test caught what that does: pooling the low-scoring deployment regime into
the calibration set drags the threshold down and the measured miss rate fell
from **0.76 to 0.19**. The baseline looked four times healthier than it is,
which would have *understated the very collapse it exists to expose*.
`calibrate_naive` now takes `calibration_group`, and the trap has its own
regression test.

### Tool 1 — the guaranteed backbone

Threshold = the `k`-th smallest score among that group's hallucinated
calibration regions, `k = floor(alpha * (n+1))`. For exchangeable scores the new
positive's rank is uniform on `1..n+1`, so

```
P(miss) = P(S_new < S_(k)) = k / (n+1) <= alpha
```

exactly, with no slack beyond the flooring.

### Tool 2 — the primary contribution

Weighted split conformal (Tibshirani et al. 2019) mirrored to the lower tail.
Calibration weights normalise together with a test-point weight, and the test
point contributes an atom at `-inf`:

```
p_i = w_i / (sum_j w_j + w_test)
tau = inf { s : p_test + sum_{i: S_i <= s} p_i >= alpha }
```

The `-inf` atom is what makes it conservative — it consumes `p_test` of the
lower tail before any calibration score counts, pushing `tau` down. Dropping it
yields a tighter-looking threshold that is not valid, so a test asserts the atom
never raises `tau`.

**Weights** are an exponential kernel in D19's operator distance,
`w = exp(-d/h)`, with `h` defaulting to the median non-zero distance (D33). A
hard cut-off was rejected: it is a Mondrian group with extra steps, and it
discards the near-neighbours that carry most of the information about a nearby
operator. The exponential lets a deployment operator sitting *between* two
calibration regimes borrow from both — the case Tool 1 structurally cannot serve.

---

## Honest scope

Tibshirani's guarantee holds when the weights are the true likelihood ratio
between deployment and calibration distributions. **A kernel in operator
distance is not that ratio.** It is a defensible surrogate — and operator shift
is a change in the measurement process rather than a covariate shift (D6), so no
exact finite-sample guarantee is claimed for Tool 2.

This is why D3 makes Tool 1 the backbone and ships it first. Tool 1 carries the
exact statement; Tool 2 is the reach result; the residual gap between them is
what Track 3's bound (T3.3) quantifies. Effective sample size is reported on
every weighted calibration so the cost is visible rather than inferred.

---

## Thin groups: refuse, don't certify

With `n` positives the smallest achievable miss-rate bound is `1/(n+1)`, so
certifying `alpha` needs `n + 1 >= 1/alpha`. **At `alpha = 0.1` that is 9
positives per group.** Below it, no threshold is valid at the requested level.

`min_positives()` makes D3's "thin groups give noisy thresholds" checkable
rather than merely acknowledged, and `CalibrationReport.reportable` is false
whenever any group falls short. For Tool 2 the same test is applied to the
**effective** sample size, since a weighted threshold can rest on far fewer
effective examples than its raw count suggests.

This is also where T1.2 found a defect in the reference implementation it
supersedes — see D32.

## Verification

15 gates in `tests/test_calibration.py`, Monte-Carlo where it counts:

- **Measured miss rate tracks the promise** for Tool 0 and Tool 2 under no shift — not merely bounded by it, but not far below either, since an over-conservative flag is its own failure.
- **The central claim in miniature:** naive transfer collapses to a **0.76** miss rate at nominal 0.1; Mondrian restores it to within 0.05.
- **Thin groups refuse** at n = 5 and certify at exactly n = 9.
- **A ceiling rule would over-promise**: thresholding on a single positive gives a measured miss rate of ~0.5, five times the promise. The test pins the arithmetic that avoids it.
- **The `-inf` test atom never raises `tau`.**
- **Tool 2 serves a 3-positive group that Mondrian refuses**, borrowing enough weight from a neighbouring regime to clear the ESS bar — Q4's case, demonstrated.
- **Unknown groups are flagged wholesale** rather than left unflagged.
