## 1. The label, implemented once (D-061)

D-061 replaces the label's last three versions (D37's τ, D57's floor, D60's gate) with one: **absolute, `err_free > ε`, ε a quantile of `err_free` on each substrate's own design split, frozen.** The anatomy confound moves out of the outcome and into the analysis, by stratifying on `free_content`. D-061 names no quantile; **q75** is the one its table tested, and it is the default here.

**One definition, every script (P-19).** `label_spec()` in `evaluation/bank.py` returns a `LabelSpec`: the name, a one-line description each script prints, and the arguments for `derive_score_and_label`. `add_label_args()` gives every reporting script the same four options:

- `--label {absolute, candidacy, ratio}`: absolute is the default; the other two reproduce earlier numbers.
- `--label-quantile`
- `--tau`
- `--require-annotation`: D-061's secondary MRI reading.

The ten scripts that compute a label-dependent number now share it. That includes Track 1's `select_weights.py` and `tool2_holdout.py`, and it replaces each script's own gate code from T2.5. `derive_score_and_label` gained the `require_annotation` passthrough it lacked.

**Checked, not assumed.** `--label candidacy` reproduces T2.5's whole coverage table **identically**, so the refactor changed no number it should not have. 6 new tests pin:

- q75;
- that the absolute label is `err_free > ε` with no division and no gate;
- that ε comes from design rows only;
- the superseded labels;
- the annotation reading;
- the refusal of a bank with no design side, which tells the user to read `--label ratio`.

| | MRI (`w05`) | CT (`w07`) |
|---|---|---|
| ε (q75 of `err_free`, design split) | 0.906 | 0.360 |
| ε re-valued over 13 splits | 0.862–1.075 | 0.288–0.432 |

The absolute label puts few positives at low acceleration. On MRI the test-side positive rate runs from 0.9% (`variable_density2d R2`) and 5.3% (`random1d R2`) to 61% (`random1d R8`).

## 4. Detection, stratified as D-061 requires, and why it says little

`stratified_detection.py` applies Track 1's `attribute_components` one operator at a time, with three `free_content` strata, beside **the anatomy control**: `free_content` itself scored through the identical path, which D62 calls the load-bearing comparison.

| | MRI | CT |
|---|---|---|
| Detail-matched AUC, `s_free` | 0.955–1.000 | 0.929–0.997 |
| Anatomy control's own | 0.27–0.65 | 0.61–0.68 |
| Excess over the control (combined score) | 0.33–0.73 | 0.30–0.38 |
| Verdicts | all 45 "invention-driven" | 35 of 36; `s_residual` at `v180` "anatomy-confounded" |

**These numbers are arithmetic, not evidence, and D-061 said they would be.** With this prior, `cos θ` between the reconstruction's and the truth's free components is ~0.07 (D-061). So by D-037, `err_free² ≈ s_free² + free_content²`:

| | Spearman(`err_free`, √(`s_free`² + `free_content`²)) | median gap | Spearman(`s_free`, `err_free`) within `free_content` terciles |
|---|---|---|---|
| MRI | 0.989 | 2.7% | 0.998, 0.986, 0.854 |
| CT | 0.991 | 1.7% | 0.999, 0.996, 0.951 |

Within a `free_content` stratum the absolute label is almost a monotone function of `s_free`, so any score built on `s_free` ranks it nearly perfectly. The excess over the anatomy control is real arithmetic but not detection: the control knows `free_content`, while `s_free` all but *is* `err_free`. **D-061: "No criterion can be validated against this prior."** The verdicts are recorded and not read as Q6's answer; that needs a prior that recovers hidden content.

The coverage results of §2–3 are not affected. They are statements about calibration under shift for a fixed label, not about whether the label is invention.

## 5. The annotation-restricted reading (MRI, secondary)

D-061's secondary MRI reading requires a positive to lie in a fastMRI+ annotated region (`ann_coverage ≥ 0.10`). That is the one anchor not defined by the project's own arithmetic. **On this bank it is too sparse to calibrate:**

| | |
|---|---|
| Annotated regions | 1.6% of all regions |
| Positive test regions per operator | 0–178, from 0–18 patients |
| `random1d R2` (the ascending calibration operator) | 2 calib positives from 1 patient, 0 on test |
| `variable_density2d R2` | none on any side |

The ascending direction cannot be calibrated at all: there is no threshold, so naive transfer flags everything. The descending direction's intervals span 0.47–1.00. It is reported for completeness (`mri_coverage_annotated.csv`), not as a result. A useful annotation-anchored reading needs a larger annotated set than fastMRI+'s knee boxes on 96 patients.

## 6. CT operator distances (D-061, D64)

`ct_distances.py` computes every registered measure on D-061's ~k+1 pairs:

- the calibration operator (180 views) against each of the 8 deployment operators;
- an arc change at fixed views (`v120` 180° → 90°);
- a view change at fixed arc (`v120` → `v60` at 180°).

The operators are rebuilt from the bank's own manifest. The heavy calls (the CG solves inside each projection) run on the GPU through a thin proxy, while the probes are still drawn on the CPU with their usual seeds. Against a CPU run of the first pair it agreed to 0–1.1%: `spectral_divergence` exactly, `null_space_growth` 0.3737 against 0.3776. That is inside the 32-probe Hutchinson estimate's own spread, and 4.5x faster (885 s against 196 s for that pair). All 10 pairs took 28 min.

`operator_norm` is **undefined across view counts**, because the sinograms have different shapes. It exists only for the arc-change pair (11.77).

**Which measure orders CT's coverage gaps?** Rank correlation with the ascending naive gap (0.90 minus the 13-split mean coverage, §2), over the 8 calibration pairs:

| Measure | ρ |
|---|---|
| **`null_space_growth`** (D-053, signed) | **+0.976** |
| `null_space_projection` | +0.762 |
| `chordal_subspace` | +0.762 |
| `spectral_divergence` | +0.595 |
| `sampling_support` | −0.180 |

- **D-053's directional measure is the one that tracks the gap**, and it does so almost perfectly. That is T1.3's cross-modality item answered on a real CT pair set: the measure locked on MRI orders CT's failure too.
- **The five measures differ on CT, as D-061 expected.** Their rank correlations across the 8 pairs run 0.46–0.79. On MRI four of five coincide, because a mask is diagonal in k-space (D-052). The one exact agreement, `chordal_subspace` with `null_space_projection` (1.00), is an identity, not a finding: `d_c² = ½‖P_A − P_B‖²_F`.
- **`spectral_divergence` runs for the first time,** and is graded along the view axis (1.0 → 4.3). It is out of order on the arc axis, though (a90 is its *smallest*, at 0.24), so it orders the gaps less well.
- **Range and null space come apart on the arc axis, not the view axis.** For a view change, the signed growth nearly equals the symmetric distance (0.409 against 0.405; v180 → v30, 0.602 against 0.606): thinning views mostly *adds* hidden directions, a nearly nested null space. An arc change at fixed views moves the null space sideways (0.280 against 0.525), so hidden directions are lost as well as gained. The limited-angle departures from 180 views sit between the two (0.68–0.98 of the symmetric value). This is what made the arc axis the stronger test (D-061).

`sampling_support` fails on CT (ρ < 0) because its angle-set heuristic counts which angles are kept, not what they measure.

## 7. Dose: not a grid axis (D-061, D63)

As ruled. Dose changes the noise, not `A`, so every operator distance between two doses is exactly zero: two cells at the same x on the headline axis, with no sign to recover. It would also multiply the `ct/{family}/v{views}/a{arc}` groups against D32's positive floor. `photon_count` stays unapplied. D-061's suggested **robustness check at one fixed geometry** belongs in an appendix and is not built yet.

## 8. Honest limitations

- **Not reportable.** The face prior on both modalities (D-016, D-035).
- **No external validation of the label** (D-061, T2.5 §6.1). The criterion is the project's own. The published Hallucination Index does not agree with it (kappa ≈ 0), and the annotation anchor is too sparse here (§5). This is a stated scope limit for the write-up.
- **Detection numbers cannot be read under this prior** (§4). Q6's verdict waits for a prior that recovers hidden content.
- **q75 is our reading of D-061,** which names no quantile; it is the one D-061's table tested.
- **The absolute label empties the low-acceleration MRI cells** (`variable_density2d R2`: 200 positive regions, 5 patients). A coverage there is not estimable, and is marked so rather than reported.
- **CT distances rest on 8 calibration pairs and 32 Hutchinson probes.** ρ = 0.976 over 8 points is strong but not precise, and the probe estimate itself varies by ~1%.
- **CT is 100 of 1,228 TotalSegmentator subjects** (P-10), with one subject assumed to be one patient (T2.6 §1).
